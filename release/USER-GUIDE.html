SHY-CAMEO · 使用说明

入画

主角是你，故事里的角色有点害羞。

用 1–2 张已获同意的成年人照片，准备五张 3:4 写真，按你想经历的故事安排。角色不露脸，主角清楚露脸。

验证范围开始使用授权与费用隐私安装与回退排障

7 类能力，15 种玩法

  • 和角色同框：在剧组待一天、一起过日子、进入他的世界、让角色当旅行导游。
  • 扮成一个人：中国戏曲、外国角色戏曲扮相、换上角色的衣服。
  • 走进一个故事：原著情节、类型片、电影场景、原创角色冒险。
  • 自己去旅行：一个城市或几个国家。
  • 和宠物过日常：熟悉的陪伴和自然互动。
  • 我的舞台：本人当主唱、吉他手、鼓手等，投入狂热现场（试验功能）。
  • 去听 TA 的演唱会：本人当观众，歌手或乐队在远处舞台表演（试验功能）。

两种演唱会玩法及乐队互动已纳入 v1.1.0-rc.1 安装包，仍属试验功能。东京观演五张获整体正向反馈；电吉他手五张已获整套认可，吉他和鼓手另有单张实拍。它们仍属试验，不证明真人身份或全部乐器动作稳定。

可调整衣装、画风、光线、机位与动作，也可只改某张并保留旧版。案例集展示 13套五张故事＋3张互动补充＋1组四张摇滚选集，共72张获认可的AI模特成片，包括东京1992观演套图和我的舞台电吉他套图；各页保留实际反馈范围，不代表真人锁脸或精确身体控制已经通过。观演还可按艺人、年代和偏好规划门票、场刊、应援物的取得、使用与收纳；这项新版物料指导尚无对应五张实拍。我的舞台也可安排与原创成年队友合奏、向鼓手示意或共同谢幕，仍以本人为主角；明确独奏时不加队友。合奏、鼓手回应和共同谢幕三张已获选用，谢幕采用修正鼓组位置与贝斯琴颈后的版本；这是三张补充样本，未另算一套五张。另有《最后一个和弦》四张选集获作者正向反馈并收入正式案例；乐器问题和第五张结果待核的说明随图保留，不增加完整套图数。角色导游等尚无本次已认可展示套图的方向仍属试验；其余各项按具体案例范围理解。

同角色，多系列持续创作

只修改已认可画面的某个细节时，可直接说“只改第3张袖口颜色，旧版保留”。技能用 compile-edit 从指定底图编译修改，明确要求生成才提交一次；新版经你验收和选择后才替换当前选用版。编译本身不生图。

可以一次选择剧组、练功、美食等多个系列，每套五张；也可以下次继续。全部仅指当前展示并选定的系列。已有照片与偏好沿用，结果按系列展示，重拍保留旧版。

公开测试能力；孙悟空多系列选择、续作与返回整理，以及电影阿拉贡和电视剧梅长苏的方案准备已完成限定范围无图评审。“全部”后新增候选不扩大当次范围；重拍结果未知时先核查，旧版保留。实际画质、精确妆造与多次稳定性仍未验证。未验收图片不标完成。项目进度保存在用户私有工作区，临时目录不保证长期留存。

开始使用

默认包小于5MB；下载和配置通常需要几分钟，取决于网速与宿主。选择可选图库时，请为下载与解压另留约120MB磁盘空间。下载需要联网，安装和本地检查不生图；真正开拍按账号额度与服务计费。在线案例链接是补充材料，本说明与本地操作无需加载远程资源。

默认用 Codex 自带的 skill-installer 安装固定版本。在新对话发送：

请使用 skill-installer，从 https://github.com/denggui-ai/shy-cameo-skill
安装 skills/shy-cameo 目录，版本固定为 v1.1.0-rc.1。
只安装，不生图。已有同名安装时先核对位置与版本。

安装器写入当前用户的 Codex 技能目录，实际位置以返回结果为准；已有同名目录先备份到扫描目录之外。不要同时启用独立技能和入画插件。需要 Python 3.9+，真正开拍另需当前会话支持内置生图、已登录账号与可用额度。本版默认安装已拆分图库，需要图片时按 INSTALL.md 手动下载匹配附件；未下载时正常使用文字自述。

安装后新开对话，核对技能列表或发现接口指向本次安装；将下面的路径替换为实际技能目录，运行两个本地检查：

python3 -B "<skill-dir>/scripts/cli.py" --help
python3 -B "<skill-dir>/scripts/cli.py" validate-library

预期帮助正常、库验证返回 ok: true，不会生成图片。仅需要 ZIP 校验或插件管理时再读下方进阶安装；完整步骤见 INSTALL.md。

直接说想和谁、去哪里、扮成什么样或经历什么，不需要选择内部分类。已有明确想法就准备方案；只有影响画面的缺项才简短补问。已确认照片和衣装沿用。只准备时不要求登录图像服务，缺素材列为生成前待办；技能保存草稿并做可用的本地结构检查，不伪造确认、不提交生成。

你会看到一句画面概括和五张分镜，可直接要求“第三张改成……”。“确认分镜，先不要生图”只保存确认；明确要求按方案生成才进入拍摄。生成后报告实际结果，失败不自动重试，成片待你验收。

明确要拍，就按已定范围执行

一套固定五张，说“按这套拍”或“开始生成”即可；对刚才明确的拍摄提议回答“同意”也可，不重复要求数字。说“先看分镜、不生图”就只准备；开发、安装或讨论中的“继续”不当作拍摄请求。额外定妆表只在用户要求时生成；明确说“重拍第三张”即可开始该张一次新任务。Codex自身权限按宿主正常流程处理，本技能不新增安装审批。

生图前登记授权、卡片、照片与待提交状态；若用户要求先开发台账并本地提交，必须先完成。被拒、超时或没取得图片也按已提交次数记额度；第 1 张失败时其余四张取消、不提交。失败不自动重试，不改词绕过平台拒绝。不自动补拍；用户明确要求重拍时按该范围执行。开发版经典观演先生成核心舞台图，按故事顺序交付；仅预先明确允许一次内容不同的观众故事替代时，原请求与替代合计最多6次，拒绝和未知记录仍保留。

中途按 Ctrl-C 或关闭终端后，先查套图账本；进程终止处理与已提交次数分别核对，不能猜剩余额度或自动续跑。CLI 未返回明确原图路径时，不挑其他会话的最新图片冒充结果。

照片去哪里

读取范围：你主动放入私有工作区的照片、确认的参考和技能自带规则。原始自拍、同意记录与私人日志放仓库外，不公开；生成成片仅在用户明确授权的范围内制作案例副本，生图授权不等于发布授权。生图参考会经你自己的 Codex 账号发送给 OpenAI；并非全程离线。本项目不收集你的照片、不提供托管服务、无项目级分析遥测；宿主与服务提供方的数据处理按其自身政策。

工作区会保留 input、cards、characters、outputs、审计日志、同意和额度记录；CLI 生图的原始文件可能先由宿主写入它自己的生成目录。若用户要求只留私有工作区，原图原字节转移后核对哈希，不保留工作区外副本。交付原图不重编码，C2PA 如有则保留；可选角标另存派生件。

项目没有自动到期删除。结束后先备份需要保留的原图与授权记录，再在文件管理器中删除自己指定的工作区和核实过的宿主副本；卸载技能不等于删除这些数据。不要分享 consent、自拍、完整提示词、日志、账号 token 或 API key。

安装本地包

先保留旧包与摘要，确认没有同名安装。将解包后的 shy-cameo 目录放到自选 market-root 的 plugins/ 下；在 market-root 下新建 .agents/plugins/marketplace.json，内容如下。source.path 相对 market-root，不相对 .agents/plugins/。

{
  "name": "shy-cameo-local",
  "plugins": [{
    "name": "shy-cameo",
    "source": {"source": "local", "path": "./plugins/shy-cameo"},
    "policy": {"installation": "AVAILABLE", "authentication": "ON_INSTALL"},
    "category": "Productivity"
  }]
}

将下面的 /absolute/path/to/market-root 换成实际目录。命令修改当前用户的插件登记与缓存，不需管理员权限。

codex --version
codex plugin marketplace add /absolute/path/to/market-root --json
codex plugin add shy-cameo@shy-cameo-local --json
codex plugin list --marketplace shy-cameo-local --json

应返回1.1.0-rc.1的版本与 installedPath，列表应显示 installed: true、enabled: true。安装后新开会话，再确认技能“入画 shy-cameo”被发现。上一公开版补验中，发现接口返回名为 shy-cameo:shy-cameo 的启用技能，路径来自本次安装缓存；仅文件存在或插件列表有记录还不代表技能发现。若客户端没有技能列表，需用其发现接口核对，不声称桌面界面已验证。

进入 installedPath，运行本页的 validate-library 等零额度检查。无需生图来确认安装。完整布局与边界也见包内 INSTALL.md。

升级与卸载

备份旧包及 marketplace 指向的旧源目录；将 plugins/shy-cameo 更新为校验过的新版，再执行相同 plugin add 命令。核对返回版本、新会话发现路径和零额度检查。v1.0.0→v1.0.1 隔离跨版本刷新曾实测；本版升级以当前宿主实际安装结果为准；同版本覆盖、Git市场自动升级、任意历史数据迁移与回退未验证。旧四张卡仍需补充分镜并重新确认，账本不能直接当五张使用。保留独立私人工作区。

codex plugin remove shy-cameo@shy-cameo-local --json
codex plugin list --marketplace shy-cameo-local --json

卸载后应无 installed 记录，新会话不再发现此插件技能。v1.0.1 历史验证同时确认插件缓存删除、独立合成工作区文件保留。若 marketplace 只供此插件使用，可另执行：

codex plugin marketplace remove shy-cameo-local --json

marketplace 源目录、照片、成片和工作区不是卸载技能的清理目标，是否删除由你另行决定。不要用全盘清理命令。上述命令以 CLI 0.161.0 实测为依据，其他版本先看 --help。

遇到问题

  • blocked_consent：先完成主体／成年／照片哈希授权；换过照片要重新确认。
  • blocked_quota：未设置本次生成范围的内部次数上限，或这次次数已用完；不能偷偷续拍。
  • set_size_changed：旧四张卡需要按本次故事补足五张并确认。
  • failed_no_image：本次没取得明确原图路径，额度可能已扣；不要拿其他会话的图或自动重试。
  • 构图检测不可用：人工核对主角脸、角色不露脸、道具和景别。
  • 平台拒绝：原样转告，不能改写绕过。
