# 入画能力清单

## 能拍什么（唯一标准）

文档与代码以本节为准；改动 skill 时先对照本节，冲突时改代码或文档，不改本节。题材不受限制，你点名任何角色都照拍；“档位”只说明我们验证到哪一步，涉及权利的说明不是法律意见。

- **稳定**：在当前规则下真实拍过整套 5 张，并经作者看过、认可。
- **试验**：功能已有，但只在旧规则下拍过整套，或还没人评、评了没过。我们会告诉你“这个还在试验，效果没保证”。
- **排期**：还不能用（见下文）。

**可加项**（随时可说，不说就用默认）
- 画风：真人照片感（稳定，默认）；我和背景都变动漫（试验）；我保持真人、背景变动画（试验）。
- 衣服：有照片时按人推荐，没有就用场景默认；方案里写一行，可改。在别的类里换角色的衣服只改这一项，不换类。
- 拍几套：一套、接着拍（稳定）；全部拍（试验）。
- 带上宠物（试验）：在别的类里带上自家猫狗，一张清楚的宠物照整套共用；封面必有它，默认五张都有（抱着、跟着、依偎）。
- 交付附送：发帖文案草稿（试验，纯文字，可不要；发布及 AI 生成声明由您自行负责）；本地作品页（试验）。

一句话怎么归类（按顺序判，命中即停；没命中的要求写进方案，不丢）：说了让角色带路 → 带你去旅行；点名想陪着的角色 → 类 1（去哪、做什么写进方案）；整套就是唱戏或穿某身衣服拍写真 → 类 2；说了原著、作品、片型或原创角色 → 类 3；说了自家宠物、没点名角色也没说去哪 → 类 5（点名了角色或地点就按那一类，再加“带上宠物”）；只说了地点 → 类 4；都不像 → 给菜单。

## 你要准备什么

身形信息按当前画面需要使用：有身体照片时参考清楚可见部分；只有头像时可补充自述，不要求全身三视图。明确局部调整可写入生成要求并检查结果，现有合成图库仅供需要时沟通差异。精准身材／胸型控制及换装、侧背视角稳定一致性尚未验证；这项基础支持不提升任何玩法的档位。

- 一张清楚的正脸照就能拍（多给一张侧脸是否更像，还没做过对照）。
- 带宠物时再给它清楚的照片：它占满画面、睁着眼、看得见全身，须是你自己的宠物；有几张不同姿势的可以一起发，目前挑最清楚的 1 张用；照片也会发给生图服务。
- 只能是成年人：你本人，或已经同意的成年人。
- 照片里的人如果不是你，请先告诉对方要做什么，并取得对方单独同意。
- 拍什么一确定就要照片，一条消息说完；先不发也可以先看方案，开拍前再要。同一张照片之后复用。

## 你会拿到什么
- 每套 5 张竖图（默认 3:4），像一个小故事：地点、时间、机位、动作有变化。
- 每套 1–2 张清楚拍你的正脸（封面和最动人的那张）；其余拍背影、手、越肩、剪影或远景，靠整套不变的发色、衣服和首饰认出你。
- 原图不重编码，保留生图服务带的 AI 生成标识；想要可见角标可以另存一份。
- 拍完一套会问你要不要接着拍，并给 3 个新系列；你选哪套再拍哪套。可以先看五张的情节再决定拍不拍，可以说“第 3 张改成……”，拍完可以只重拍某一张，旧版保留。

## 先说清楚的限制
- **像不像**：正脸最像；人脸漂移还没解决，不承诺每张都稳定像你；转头、大动作、全身远景更容易走样；手偶尔会画错，拍完逐张检查。
- **封面**：机器比脸提示偏低时会先停下给你看；机器没法检测时会直接告诉你，不说成“已经确认像”。
- **隐私**：原照只存在你自己电脑的工作文件夹，不进仓库、不公开；照片会发给生图服务，按该服务的规则处理（我们不能替服务承诺不用于训练）；删掉文件夹只删本地副本。
- 默认保留你的发型（可加头饰）；戏曲扮相或你要求改发型时会改，改了更容易不像你。靠发型妆容让人认出的角色容易不像你或认不出。
- 雪人、机器人这类靠脸认的角色，不露脸可能认不出来，拍之前会先提醒。
- **额度**：每张提交给生图服务就算一次，失败也算。第 1 张失败，这套剩下的不拍、不花；第 2–5 张某张失败，其余照拍，只交付成功的；都不自动重拍。
- 生图服务拒绝时原样告诉你，不改写提示词绕过。
