## 状态怎么读

| 状态 | 含义 |
|---|---|
| 已验收 | 本行明确写出的样本或检查范围通过；图像行指用户对所选版本的反馈，不保证普遍稳定 |
| 待验收 | 已有输出，尚缺对应的用户结论 |
| 已测未通过 | 已运行且留下失败、需修订或仅部分满足的证据 |
| 未测 | 指定版本和范围没有完整运行证据；有历史、代码或准备证据时另列，不抹掉它们 |

“基本认可”“整体认可但保留问题”保留原判词，不改成逐项完美通过。历史 `stable` 只表示有作者认可的五张案例；不等于当前安装包所有场景均通过。治理状态为 `released`（公开测试版），未完成的完整流程仍为 `candidate`；不宣称 `production-ready`。
