## 零额度快速检查

在解包后的源码根目录运行：

```bash
python3 -B skills/shy-cameo/scripts/cli.py --help
python3 -B skills/shy-cameo/scripts/cli.py validate-library
```

预期：显示CLI帮助，规则库校验输出 `ok: true`。命令不生成图片、不上传照片、不安装技能、不修改全局配置。

技能源目录是 `skills/shy-cameo/`。[安装、升级与卸载步骤](../INSTALL.md)中的旧版 v1.0.1 流程曾在 macOS arm64 / Codex CLI 0.161.0 的全新隔离配置验证，使用原生本地插件管理和独立宿主发现接口。当前版本已补新装与发现；升级、卸载与回退仍沿用历史范围，未复验完整安装生命周期。目录可见、技能发现、模型触发和真实出图分别核对；桌面界面及其他平台未验证。完整说明见[离线使用指南](../USER-GUIDE.html)。

初次请求示例：

> 用 $shy-cameo 帮我准备一套五张故事分镜，先不要生图。照片将放在仓库外私有工作区。

只准备整套分镜时，不要求登录生图环境；执行可用的姓名扫描，保存并校验五张未确认的 JSON 分镜与套图卡；Markdown 展示不替代卡片。缺照片、角色资料与服饰参考另列待办，不编译、不登记提交、不生图。本机 CLI 的新会话显式文字准备已验证；这不代表生成就绪或图像工具开启时的授权硬拦已验证。

确认分镜和成年人照片同意后，直接说“按这套拍”即可生成五张，不用重复报张数或使用授权口令；对明确拍摄提议回答“同意”也可。说“先看分镜、不生图”就只准备，开发或安装语境的“继续”不会触发拍摄。已提交的失败或超时也可能消耗额度；第一张失败取消其余，失败不自动重试。

## 隐私与费用

照片、同意记录、卡片、日志和成片放在仓库外的私人工作区，不提交本仓库，不上传到维护者或公开Issue。生成参考通过你自己的宿主和账号发送给图像服务；这不是全程离线工具。费用与限制取决于你的服务和账号，本项目不承诺免费额度。

本公开仓库仅包含白名单中经审核、同意公开的展示图及合成参考素材；未获公开授权的人像、研究记录与旧 Git 历史不随此仓库分发。本项目不附带原始自拍或私人记录。只有生图同意不等于照片可公开分发。反馈问题时仅提供版本、系统、退出码与脱敏错误摘要，不提供完整日志、参考图、授权文件或凭证。

## 已知限制

- 安装走Codex正常插件流程，本技能不另设安装审批或“授权几张”口令。原生工具没有本技能提供的提交前程序硬拦；真实工具开启时的零提交授权边界实测未完成，作为已知限制延后，不标记为通过。用户意图、既定次数上限及失败不自动重试规则仍保留。

- 服饰结构、帽型、补丁、景别和本人相似度仍可能偏离；不承诺精确传统服装复原或稳定写真效果。
- 网页资料只供写卡理解，不会自动进入图像参考。以实际request的referenced_image_paths为准；scene-ref只借环境/光线，不是服饰结构参考通路。角色定妆表也不等于用户穿衣保真。
- 本机Codex原生济公五张生成、登记和原字节交付已实际走通，用户认可整体效果并保留；本次完整调用窗口审计及独立复核通过。用户已追加逐张确认本人感、角色辨识和无明显异常或角色露脸，五张均accepted；该样本通过不代表任意题材效果保证，不代表模型在任何未来提示下均不会误调图像工具。其他宿主成片未验证，不附带已验收金牌人物模板；黛玉辨识方向暂停承诺效果。
- 角色不露脸是生成约束，仍需目视检查。年龄依用户声明，不做机器判断；相似度也由用户确认。
- 自动审计只在唯一明确的request读取边界可确定时限定连续窗口；复杂动态调用或边界不足保留unverified。原始失败必须保留，不能挑选匹配提示词制造pass；服务输出事件与图片的端到端关联仍未完成。
