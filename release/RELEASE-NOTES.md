# 入画 v1.1.0

入画把一句想法设计成五张故事写真。可以和角色同框、换装、进入故事、旅行、和宠物过日常，也可以登台演出或去看演唱会。

- [案例集首页](https://denggui-ai.github.io/shy-cameo-skill/site/)提供七类玩法、13组案例和入门提示。
- [安装指南](https://github.com/denggui-ai/shy-cameo-skill/blob/v1.1.0/release/INSTALL.md)提供固定标签安装、插件 ZIP 校验、升级及卸载步骤。
- 下载插件 ZIP 和同名 SHA-256 文件后运行 `shasum -a 256 -c shy-cameo-1.1.0.zip.sha256`。解压后可离线打开 `user-guide.html`。

舞台与观演为试验功能。成图需要逐张确认。可选身形图库见 [预发布附件](https://github.com/denggui-ai/shy-cameo-skill/releases/tag/v1.1.0-rc.1)。
