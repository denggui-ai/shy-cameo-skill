# v1.1.0-rc.1 — 入画：演唱会与乐队互动

本次预发布把“我的舞台”“去听 TA 的演唱会”和乐队互动纳入安装包。旧版本标签与附件保留，已有安装不会自动更新。

## 新增

- **我的舞台**：本人可当主唱、吉他手、鼓手、贝斯手或键盘手；保留所选动作、表情与舞台氛围。可与原创成年队友合奏、回应鼓手或共同谢幕，明确独奏时不加队友。
- **去听 TA 的演唱会**：本人在台下，歌手或乐队在远处舞台；通过服饰、乐器、动作与舞美辨识，不扩展近距离明星合照。
- **故事顺序**：经典观演先生成核心镜头，按入场至散场交付。仅在预先明确授权时追加一次实质不同的观众故事替代；保留原失败、取消、未知记录与旧选版。
- **案例与说明**：13套五张故事＋3张获选互动补充，共68张；英文首页、中文入口、安装与离线指南同步到本版。

## 安装与升级

使用Codex自带的skill-installer，从 `denggui-ai/shy-cameo-skill` 安装 `skills/shy-cameo`，固定标签 **v1.1.0-rc.1**；也可下载下方插件ZIP和SHA-256。先备份旧版，只保留一种安装方式，安装后新开对话。详见[安装指南](https://github.com/denggui-ai/shy-cameo-skill/blob/v1.1.0-rc.1/release/INSTALL.md)。安装不生图。

默认轻量包小于5MB。可选身形图库仍为20261102版，与v1.0.3-rc.1附件原字节一致；已有该图库无需重下。没有图库也可正常使用。GitHub自动提供的Source code是开发源码，不是插件安装包。

## 验证与限制

- 已认可的东京观演五张、电吉他五张和三张互动为虚拟成年主体样本，不证明真人身份、强表情或精细乐器结构稳定。
- 观演物料新版尚无对应五张实拍，互动文字用例282–284仍未运行。自动调用审计无法唯一定位请求窗口时保持unverifiable，不能借用用户认可代替审计。
- 旧版v1.0.3-rc.1的六次限定自动发现结果属于历史证据。本版未新增模型首用、隐式触发、新物理机器、桌面点击、升级回退或真实生图验证。
- 本版运行技能沿用已发布main的内容，打包本身不调用图像服务；首张失败停止、未知结果保留claimed、进程组整体停止及不自动重试的规则保持不变。
- 67项发布相关检查通过；ZIP安全与逐文件摘要、干净解压后的CLI/规则库、舞台互动与观演编译、故事顺序、离线指南桌面/手机/打印检查通过。没有重复执行真实生图。
- 基础技能格式校验通过。通用strict扫描保留一项标题匹配误报：未识别“主流程”；独立复核确认八步流程完整、非发布阻断，原始FAIL未改成通过。状态为预发布，不声明production-ready。

## 校验附件

下载两个ZIP及各自的SHA-256，在同一目录运行：

```bash
shasum -a 256 -c shy-cameo-1.1.0-rc.1.zip.sha256
shasum -a 256 -c shy-cameo-body-reference-20261102.zip.sha256
```

预期均为 `OK`。摘要应来自可信发布记录；同处下载不能单独证明发布者身份。包内离线 `USER-GUIDE.html` 说明使用、隐私、升级回退与卸载，`PROVENANCE.json` 提供逐文件摘要和证据边界。
